Natural languages are superb for humans and quietly hostile to large language models: they shatter at token boundaries, hide who did what, and let one string mean two trees. Nex is a token-native language — one atom, one meaning, one parse — built for next-token prediction, embedding geometry, and systematic generalization.

What is actually wrong with natural language for LLMs

Not vibes. Failure modes that show up in tokenizers, attention, and compositional generalization papers.

1. Tokenization is not morphology

BPE optimizes compression, not meaning. It will cut a stem in half and keep Apple / apple / APPLE as strangers. Nex refuses to have a writing system that is not the vocabulary.

2. Ambiguity is a training-set tax

Every English sentence the model sees is compatible with multiple graphs. It spends capacity on guessing. Nex makes the writer choose, so the reader never does.

3. Transformers like explicit roles, short programs, and index hints

On SCAN, giving the attention mechanism abstract grammatical roles improves systematic generalization. The RASP-generalization conjecture says a decoder-only transformer length-generalizes when the task is a short program over tokens — delimiters, indices, named slots. Nex is that program: predicate first (so next-token prediction is constrained by selectional restrictions), named roles (so agt is an attention key), bindings (so coreference is equality, not a pronoun crossword), and matching parentheses (an induction-head classic).

Compositional languages are easier for both humans and nets to generalize in. Irregular morphology is not “richness” to a model; it is a sparse lookup table. Nex has none.

Grammar

A statement is an illocution plus a frame. A frame is a head, optional features, optional binding, then role–argument pairs. Operators take bare arguments. That is the whole language.

program     := statement+
statement   := illocution frame "."
illocution  := asrt | ask | cmd | opt | exch
frame       := "(" head feature* binding? item* ")"
head        := ATOM                         # event / kind / quality / operator
feature     := not | past | now | fut | done | ong | hab
             | may | must | seen | heard | said | inf
             | def | ind | mass | sg | pl | very | more | most
binding     := "=" $N
item        := ROLE arg                     # agt thm rec loc tmp cau ...
             | arg                          # only if head is an operator
arg         := frame | $N | ATOM | NUMBER

Roles are a closed list. Features are a closed list. Operators are a closed list.
Open-class roots only appear as heads. Unknown heads still parse.
Canonical order: features by slot, then roles by the role hierarchy, then modifiers.

A worked sentence

English: Maria gave John the red book yesterday because she liked him.

The English string does not say whether she is Maria, whether the red book is unique, or whether yesterday modifies the giving or the liking.
asrt ( doni past done agt ( pamo name maria = $1 ) thm ( mabo def mod ( ruga ) = $2 ) rec ( pamo name john = $3 ) tmp ( before nowt ( qnt ( dieno ) 1 ) ) cau ( fali past exp $1 thm $3 ) ) .

Why predicate-first

Autoregressive models commit left to right. If the predicate comes first, every following argument is generated under the constraint of that frame. That is the same reason doni(agt, thm, rec) is easier to fill than a verb-final language in which the model must keep three NPs in the air before it knows they are a giving.

Quantifier scope is tree structure

English nobody saw every dog has two scopes. Nex writes them as different trees: ( none $1 ( all $2 ( vidi ... ) ) ) versus ( all $2 ( none $1 ( vidi ... ) ) ). There is no “the model will figure it out.”

What we refused

  • Lojban place structures — numbered x1 x2 x3 are a memory test. Named roles are attention-friendly and omittable.
  • Ithkuil density — packing twelve categories into one word is the opposite of token purity.
  • Controlled English — still tokenized as English, still ambiguous at the boundary.
  • AMR as a language — graphs without a canonical linearization are not a language a decoder can sample.
  • A fantasy script as the primary form — extra bytes, worse BPE. Glyphs here are a visualization of type, not the encoding.

Lexicon

Closed class is grammar. Open class is small on purpose: compose not, koso, more instead of minting unhappiness and happier. First consonant loosely marks field, so related roots start nearby — in spelling and in structured ids.

Featural glyphs & structured ids

Humans get a badge that shows type. Models get a 16-bit id KKKK FFFF RRRRRRRR — kind, semantic field, root. Embeddings can be initialized as a sum of those three lookups, so every transfer-event starts in the same region of space. BPE ids cannot do this: they are accidents of merge order.

Nex is an invented language for LLMs: kernel in Python, playground in this page. Parse is unambiguous. Morphology is syntax. Reference is an index.
